# Security Policy

If you believe you've found a security vulnerability in PostShip, please
report it privately rather than opening a public issue.

**Send a report to:** tmorretton@gmail.com

Include as much detail as you can: the affected endpoint/feature, steps
to reproduce, and the potential impact. We'll acknowledge reports on a
best-effort basis within 72 hours.

There is currently no bug bounty program — this is a solo indie project,
not a funded security program. We're grateful for responsible disclosure
regardless.

Please don't test against other users' accounts or data, and give us a
reasonable window to fix an issue before any public disclosure.
